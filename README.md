## About

This is my personal portfolio — a single-page site covering my work as an AI Engineer specializing in **LLMs, agentic AI, RAG systems, multi-agent architectures, AI evaluation, and explainable AI**. It highlights featured projects, technical skills, and ways to get in touch, built with a modern React + TypeScript stack and a component library based on shadcn/ui.

## 🔧 Tech Stack

| Layer | Technology |
|---|---|
| Framework | React + TypeScript |
| Build tool | Vite |
| Styling | Tailwind CSS |
| UI Components | shadcn/ui |
| Hosting | Netlify |

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm (or Bun, since `bun.lockb` is present)

### Install & Run

```bash
git clone https://github.com/Snigdha-Gayathri/Snigdha-Portfolio.git
cd Snigdha-Portfolio
npm install
npm run dev
```

The site will be available at `http://localhost:5173`.

### Build for Production

```bash
npm run build
```

The production build is output to `dist/`, ready to deploy to any static host.

## 📜 Available Scripts

| Script | Description |
|---|---|
| `npm run dev` | Start the Vite dev server with hot reload |
| `npm run build` | Create an optimized production build |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint over the project |
